# hybrid-ITS-taxonomy
Hybrid-ITS-Assignment is a repository containing the scripts used for the taxonomic assignment of fungal OTUs generated from a hybrid dataset combining Oxford Nanopore Technologies (ONT) and Illumina sequencing. The workflow includes the integration of both sequencing platforms, taxonomic assignment using VSEARCH with the UNITE database, and the construction of a phyloseq object for downstream ecological analyses in R.

## Hybrid dataset
The hybrid dataset was generated by combining two independent sequencing datasets:
- Oxford Nanopore Technologies (ONT)
- Illumina

Both datasets targeted the fungal ITS region using the same primer pair and generated amplicons of comparable length, making them suitable for integration.
To minimize platform-specific biases, each dataset was processed independently through the bioinformatic pipeline until:
- OTU centroid generation
- Taxonomic assignment
- Construction of individual phyloseq objects
The resulting datasets were then integrated for subsequent analyses.

## Taxonomic assignment
Taxonomic assignment was performed using VSEARCH with three complementary approaches:
- SINTAX
- Lowest Common Ancestor (LCA)
- BLAST

The following reference databases were used:
- **UNITE** database (for SINTAX and LCA)
- **NCBI Bioproject PRJNA970541** database (BLAST only)

The scripts used to build the MGsC BLAST database are available in this repository, together with the corresponding publication describing the dataset.

## Repository contents

This repository includes scripts for:
- Taxonomic assignment using VSEARCH
- Integration of ONT and Illumina datasets
- Generation of taxonomy tables
- Construction of the final phyloseq object

## Downstream analyses
The ecological analyses were performed in a separate repository, including:
- Alpha diversity
- Beta diversity
- Functional analyses
- Null models
- Local and global distribution analyses
- Comparison between taxonomic assignments obtained using **UNITE** and **GSMc**
